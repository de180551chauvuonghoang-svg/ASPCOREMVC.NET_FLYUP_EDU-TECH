## 1. TỔNG QUAN CƠ CHẾ HOẠT ĐỘNG

### 1.1. Ưu điểm của giải pháp Casso + VietQR
- **Tiền về thẳng tài khoản cá nhân/doanh nghiệp** của bạn ngay lập tức, không bị giữ tiền như các cổng trung gian (VNPAY, MoMo).
- **Miễn phí**: VietQR tạo mã tĩnh/động không tốn phí, Casso gói miễn phí hỗ trợ đủ cho đồ án và quy mô vừa/nhỏ.
- **Tự động kích hoạt (Auto-enrollment)**: Khi học viên quét mã QR thanh toán thành công, Casso bắt biến động số dư và gọi Webhook về web của bạn trong vòng 3 – 5 giây để mở khóa học.

### 1.2. Sơ đồ tuần tự (Sequence Flow)

```
[Học viên]                    [EduFlyUp Web]                    [Casso.vn]                 [Ngân hàng]
    |                               |                                |                          |
    |--- 1. Bấm "Đăng ký học" ----->|                                |                          |
    |                               |--- 2. Tạo đơn Order (Pending) -|                          |
    |<-- 3. Hiển thị trang Checkout |                                |                          |
    |    (Mã VietQR + Mã đơn hàng)  |                                |                          |
    |                               |                                |                          |
    |--- 4. Quét QR & Chuyển khoản ------------------------------------------------------------>|
    |                               |                                |                          | (Cộng tiền vào TK)
    |                               |                                |<-- 5. Báo biến động ST --|
    |                               |<-- 6. Gửi POST Webhook --------|                          |
    |                               |    (Kiểm tra Secure-Token)     |                          |
    |                               |--- 7. Cập nhật Order = Paid ---|                          |
    |                               |--- 8. Kích hoạt Enrollment ----|                          |
    |                               |--- 9. Trả về HTTP 200 OK ----->|                          |
    |                               |                                |                          |
    |--- 10. Polling check status ->|                                |                          |
    |<-- 11. Báo "Paid" & Chuyển vào bài học ngay -------------------|                          |
```

## 2. CẤU HÌNH TRÊN CASSO.VN

### Bước 1: Thêm tài khoản ngân hàng nhận tiền
1. Đăng nhập [https://casso.vn](https://casso.vn)
2. Ở cột bên trái mục **Ngân hàng**, bấm **`+ Thêm ngân hàng`**.
3. Chọn ngân hàng bạn sử dụng (MBBank, Vietcombank, Techcombank, ACB, Timo, VietinBank...).
4. Nhập thông tin đăng nhập Internet Banking theo hướng dẫn mã hóa bảo mật của Casso để hệ thống bắt biến động số dư.

### Bước 2: Tạo Webhook
1. Ở cột bên phải mục **Tích hợp**, bấm **`Thêm tích hợp`** -> Chọn **`Webhook`**.
2. Điền các trường thông tin:
   - **Tên**: `EduFlyUp Webhook`
   - **Webhook URL**: 
     - *Khi deploy Railway*: `https://aspcoremvcnetflyupedu-tech-production.up.railway.app/api/payments/casso-webhook`
     - *Khi test local*: Sử dụng ngrok/localtunnel hoặc dùng tool giả lập gọi thẳng vào `https://localhost:7006/api/payments/casso-webhook`.
   - **Secure Token**: Nhấn tạo hoặc copy chuỗi ký tự bí mật do Casso cung cấp. Lưu chuỗi này lại để cấu hình vào Web.

### 3.1. Dành cho PostgreSQL (Railway)
```sql
CREATE TABLE IF NOT EXISTS "Orders" (
    "Id" INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    "OrderCode" VARCHAR(50) NOT NULL UNIQUE,
    "UserId" VARCHAR(450) NOT NULL,
    "CourseId" INTEGER NOT NULL,
    "Amount" NUMERIC(18,2) NOT NULL,
    "Status" INTEGER NOT NULL DEFAULT 0, -- 0: Pending, 1: Paid, 2: Cancelled, 3: Expired
    "PaymentMethod" VARCHAR(50) NOT NULL DEFAULT 'VietQR_Casso',
    "TransactionReference" VARCHAR(100),
    "CreatedAt" TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    "PaidAt" TIMESTAMPTZ,
    CONSTRAINT "FK_Orders_Courses_CourseId" FOREIGN KEY ("CourseId") REFERENCES "Courses" ("Id") ON DELETE RESTRICT
);

CREATE INDEX IF NOT EXISTS "IX_Orders_OrderCode" ON "Orders" ("OrderCode");
CREATE INDEX IF NOT EXISTS "IX_Orders_UserId" ON "Orders" ("UserId");
```

```csharp
using EduFlyUp.BusinessObjects;
using Microsoft.EntityFrameworkCore;

namespace EduFlyUp.DataAccess;

public class OrderDAO : SingletonBase<OrderDAO>
{
    public async Task<Order> CreateAsync(Order order)
    {
        using var context = new AppDbContext();
        await context.Orders.AddAsync(order);
        await context.SaveChangesAsync();
        return order;
    }

    public async Task<Order?> GetByCodeAsync(string orderCode)
    {
        using var context = new AppDbContext();
        return await context.Orders
            .Include(o => o.Course)
            .FirstOrDefaultAsync(o => o.OrderCode == orderCode);
    }

    public async Task<Order?> GetUserPendingOrderAsync(string userId, int courseId)
    {
        using var context = new AppDbContext();
        return await context.Orders
            .FirstOrDefaultAsync(o => o.UserId == userId && o.CourseId == courseId && o.Status == OrderStatus.Pending);
    }

    public async Task<bool> MarkAsPaidAsync(string orderCode, string? transactionRef)
    {
        using var context = new AppDbContext();
        var order = await context.Orders.FirstOrDefaultAsync(o => o.OrderCode == orderCode);
        if (order == null || order.Status == OrderStatus.Paid) return false;

        order.Status = OrderStatus.Paid;
        order.TransactionReference = transactionRef;
        order.PaidAt = DateTime.UtcNow;

        // Tự động ghi danh học viên vào bảng Enrollments
        var alreadyEnrolled = await context.Enrollments.AnyAsync(e => e.UserId == order.UserId && e.CourseId == order.CourseId);
        if (!alreadyEnrolled)
        {
            await context.Enrollments.AddAsync(new Enrollment
            {
                UserId = order.UserId,
                CourseId = order.CourseId,
                EnrolledAt = DateTime.UtcNow,
                Status = EnrollmentStatus.Active
            });
        }

        await context.SaveChangesAsync();
        return true;
    }
}
```

#### File: `EduFlyUp.Services/PaymentService.cs`
```csharp
using System.Text.RegularExpressions;
using EduFlyUp.BusinessObjects;
using EduFlyUp.Repositories;
using Microsoft.Extensions.Configuration;

namespace EduFlyUp.Services;

public class PaymentService : IPaymentService
{
    private readonly IOrderRepository _orderRepo;
    private readonly ICourseRepository _courseRepo;
    private readonly IConfiguration _config;

    public PaymentService(IOrderRepository orderRepo, ICourseRepository courseRepo, IConfiguration config)
    {
        _orderRepo = orderRepo;
        _courseRepo = courseRepo;
        _config = config;
    }

    public async Task<CheckoutViewModel> GenerateCheckoutAsync(string userId, int courseId)
    {
        var course = await _courseRepo.GetByIdAsync(courseId)
            ?? throw new InvalidOperationException("Không tìm thấy khóa học.");

        // Kiểm tra xem user đã có đơn pending cho khóa này chưa
        var existingOrder = await _orderRepo.GetUserPendingOrderAsync(userId, courseId);
        string orderCode;
        decimal amount = course.Price;

        if (existingOrder != null)
        {
            orderCode = existingOrder.OrderCode;
        }
        else
        {
            // Sinh mã ngẫu nhiên: EDUPAY + 6 chữ số (VD: EDUPAY839102)
            orderCode = $"EDUPAY{Random.Shared.Next(100000, 999999)}";
            await _orderRepo.CreateAsync(new Order
            {
                OrderCode = orderCode,
                UserId = userId,
                CourseId = courseId,
                Amount = amount,
                Status = OrderStatus.Pending
            });
        }

        var bankBin = _config["Casso:BankBin"] ?? "970422"; // 970422 là mã BIN MBBank
        var bankAcc = _config["Casso:BankAccountNumber"] ?? "0123456789";
        var accountName = _config["Casso:AccountHolderName"] ?? "NGUYEN VAN A";

        // URL tạo QR chuẩn Napas 247 của VietQR
        var qrUrl = $"https://img.vietqr.io/image/{bankBin}-{bankAcc}-compact2.png?amount={(long)amount}&addInfo={orderCode}&accountName={Uri.EscapeDataString(accountName)}";

        return new CheckoutViewModel(
            orderCode,
            course.Title,
            amount,
            qrUrl,
            _config["Casso:BankName"] ?? "MBBank",
            bankAcc,
            accountName,
            orderCode
        );
    }

    public async Task<bool> ProcessCassoWebhookAsync(string secureTokenHeader, CassoWebhookPayload payload)
    {
        var expectedToken = _config["Casso:SecureToken"];
        if (!string.IsNullOrEmpty(expectedToken) && secureTokenHeader != expectedToken)
        {
            return false; // Sai mã xác thực Webhook
        }

        if (payload?.data == null || payload.error != 0) return false;

        foreach (var transaction in payload.data)
        {
            // Quét tìm mã đơn dạng EDUPAYxxxxxx trong nội dung chuyển tiền
            var match = Regex.Match(transaction.description, @"EDUPAY\d{6}", RegexOptions.IgnoreCase);
            if (!match.Success) continue;

            var orderCode = match.Value.ToUpper();
            var order = await _orderRepo.GetByCodeAsync(orderCode);
            if (order == null || order.Status == OrderStatus.Paid) continue;

            // Kiểm tra số tiền chuyển phải >= giá trị đơn hàng
            if (transaction.amount >= order.Amount)
            {
                await _orderRepo.MarkAsPaidAsync(orderCode, transaction.tid);
            }
        }

        return true;
    }
}
```

### 4.5. Tầng `EduFlyUp.Web` (Controller & View)

#### File: `EduFlyUp.Web/Controllers/PaymentController.cs`
```csharp
using System.Security.Claims;
using EduFlyUp.Repositories;
using EduFlyUp.Services;
using Microsoft.AspNetCore.Authorization;
using Microsoft.AspNetCore.Mvc;

namespace EduFlyUp.Web.Controllers;

public class PaymentController : Controller
{
    private readonly IPaymentService _paymentService;
    private readonly IOrderRepository _orderRepo;

    public PaymentController(IPaymentService paymentService, IOrderRepository orderRepo)
    {
        _paymentService = paymentService;
        _orderRepo = orderRepo;
    }

    // GET: /Payment/Checkout/5
    [Authorize]
    [HttpGet]
    public async Task<IActionResult> Checkout(int id)
    {
        var userId = User.FindFirstValue(ClaimTypes.NameIdentifier)!;
        var model = await _paymentService.GenerateCheckoutAsync(userId, id);
        return View(model);
    }

    // API Polling: Client gọi 3s/lần kiểm tra đơn đã thanh toán chưa
    // GET: /api/payments/status/EDUPAY123456
    [HttpGet("/api/payments/status/{orderCode}")]
    public async Task<IActionResult> CheckStatus(string orderCode)
    {
        var order = await _orderRepo.GetByCodeAsync(orderCode);
        if (order == null) return NotFound(new { success = false });

        return Ok(new
        {
            success = true,
            status = order.Status.ToString(),
            isPaid = order.Status == BusinessObjects.OrderStatus.Paid,
            courseId = order.CourseId
        });
    }

    // Webhook Endpoint nhận tín hiệu từ Casso
    // POST: /api/payments/casso-webhook
    [HttpPost("/api/payments/casso-webhook")]
    [AllowAnonymous]
    [IgnoreAntiforgeryToken]
    public async Task<IActionResult> CassoWebhook([FromBody] CassoWebhookPayload payload)
    {
        var secureToken = Request.Headers["secure-token"].ToString();
        var result = await _paymentService.ProcessCassoWebhookAsync(secureToken, payload);

        if (!result) return BadRequest(new { error = 1, message = "Invalid token or data" });
        return Ok(new { error = 0, message = "Success" });
    }
}
```
